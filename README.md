Project Description:
This banking app is designed to help with user transactions including deposits, withdrawals, checking balance, and creating an account. The app stores the username and the password associated with it. Once the user enters a username, the database checks if it exists and then prompts the user for a password. If the password is correct, the user is able to perform the task they wish to complete, else, the user is prompted to renenter the passoword or create an account. In the create an account functionality, the user has the option to recieve a strong password that is randomly generated.

Setup Instructions:
Run the FINAL_MAIN.py file. The database already has some values stored from previous testing.

Feature List:

Create Account:
 - Allows the user to create an account with options for a password.
 - The username is the user's name and the password can be manually inputted/selected or randomly generated.

Withdraw:
  - Allows the user to withdraw a certain amount from their bank account.

Deposit:
  - Allows the user to deposit a certain amount into their bank account.

Check Balance:
  - Allows the user to check how much money they have in their bank account.

Create Bank:
  - Allows for a reset of the bank's information. This cannot be called by the user.
